# 光影机械｜摄影技术演化史

一个从摄影设备内部技术出发的互动时间线：从暗箱、银盐、胶片与单反系统，到 CCD、CMOS、手机摄影和计算影像。

## 在线访问

[https://daliziql.github.io/photography-technology-history/](https://daliziql.github.io/photography-technology-history/)

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run build:github
```

`npm run build:github` 生成 GitHub Pages 使用的静态文件。推送到 `main` 分支后，GitHub Actions 会自动发布。
